# C-UAS Threat Triage

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Sistema de apoyo a la decision de priorizacion de amenazas para defensa
antidrones (C-UAS). A partir de un escenario simulado de trazas detectadas
(deteccion -> seguimiento -> clasificacion), calcula una puntuacion de
amenaza explicable por traza y un orden de prioridad de respuesta para uno
o varios activos protegidos.
